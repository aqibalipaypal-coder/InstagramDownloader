# Instagram Downloader

Native Android app to download publicly accessible Instagram photos, videos, Reels, and carousel media.

## Build APK via GitHub Actions
1. Go to the Actions tab.
2. Select the 'Build APK' workflow.
3. Click 'Run workflow'.
4. After it succeeds, download the `InstagramDownloader` artifact (app-debug.apk).

## Local build
Open in Android Studio and build debug APK.
